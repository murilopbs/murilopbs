## Sobre Mim

Desenvolvedor com foco em **sistemas embarcados**, **engenharia de software em C/C++** e ferramentas para fluxo de trabalho técnico. Atuação desde o baixo nível do hardware (firmwares em ESP32/Arduino, protocolos de comunicação BLE/Serial) até o desenvolvimento de aplicações completas (extensões para IDEs, utilitários desktop, servidores web assíncronos e aplicações multiplataforma em Flutter).

- **Foco Atual**: Desenvolvimento de periféricos IoT BLE e extensões de produtividade para VS Code.
- **Hardware & Maker**: ESP32 (CYD Touch 320x240, Bluetooth Low Energy, Wi-Fi), Arduino, PocketBeagle, displays SPI/I2C e manufatura aditiva (impressão 3D).
- **Performance & Baixo Nível**: C++ moderno (C++17/20), gerenciamento eficiente de memória, algoritmos gulosos/grafos e servidores assíncronos com Drogon.
- **Multiplataforma**: Interfaces fluidas e reativas utilizando **Flutter & Dart**.
- **Áreas de Interesse**: Automação de hardware, ferramentas de desenvolvimento e ecossistema Unix/Linux.
